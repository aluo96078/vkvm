# Windows packaging

`install-service.ps1` configures the core as an SCM service with delayed
automatic start and bounded recovery actions. The interactive companion still
uses the per-user Run entry generated by VKVM, so Tray/hotkeys never run in the
service session. `vkvm.nsi` additionally creates Start Menu/Desktop shortcuts,
registers Add/Remove Programs metadata, migrates the legacy config, grants the
interactive user access to the shared `%ProgramData%\VKVM` config directory,
and starts the service. Build and installer smoke tests belong in a Windows CI
job; cross-compiling the binary does not verify SCM, ACL, or UAC behavior.
